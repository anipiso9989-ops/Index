Thinking has 2 dimensions:
- Cognitive Form - how we manipulate info
	- Abstract - concepts, models, relationships, etc.
	- Logical - propositions, constraints, implications, etc.
- Cognitive Mode - what we're trying to accomplish
	- Discovery
		- Goal: create or modify a mental model.
		- Operates under uncertainty.
		- Exploratory, flexible, relatively slow.
		- Can be conscious or unconscious.
	- Execution
		- Goal: apply an established mental model to produce an outcome.
		- Operates with sufficient certainty.
		- Efficient, procedural, increasingly automatic and fast.

Between Discovery & Execution, there exists a third stage in the process: **Consolidation**, the process of establishing and compressing the models that were found in the Discovery stage, so that automaticity is achieved and they can be deployed reliably in the Execution stage.

**Core Cycle**
Unknown → Discovery → Model → Consolidation → Execution → Feedback → Discovery

The key principle:
> Expertise is at least partly the process of converting repeated discovery into compressed, executable cognitive structures.
