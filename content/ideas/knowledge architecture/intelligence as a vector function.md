# Intelligence as a Vector Function

A system possessing inputs, unlimited memory, unlimited computation, and the capacity to discover relationships—but lacking goals—cannot be classified as intelligent. 

Intelligence is functional; it requires both inputs and outputs. A system that produces no output or action represents a functional discontinuity (a "hole in the function's curve"). The output of an intelligent system is driven by its goal.

### The Vector Model
Intelligence can be modeled as a vector function possessing both **magnitude** and **direction**:

- **Magnitude (Capability):** The raw cognitive capacity of the system (processing power, derivation speed, memory capacity).
- **Direction (Goal):** The objective toward which the capability is oriented.

$$ \text{Intelligence} \approx \text{Capability} + \text{Direction} $$

Or, mathematically:

$$ \text{Capability} = \text{Magnitude} $$
$$ \text{Goal} = \text{Direction} $$

Without direction (a goal), capability remains passive and cannot produce intelligent output.
